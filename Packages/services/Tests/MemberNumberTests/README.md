# MemberNumberTests

Covers `MemberNumberRequests` (DEV-701, DEV-1313) without a network or window: Apple's web sign-in URL (the Services ID, Arx's callback as the return URL, `code id_token` posted with `form_post`, the state and nonce, no scope), the server's hand-off accepted only with this sign-in's state and a token carrying its nonce, Cancel read as a cancel and any other scheme, path or error refused; the request sent to `POST /v1/accounts` holds exactly the provider, the ID token and, when there is one, the install day, which a server from before DEV-1323 gets again without it after a `400`, and the account's member-since day comes back with the number (a malformed one is dropped), `200` and `201` give the number and day while any other answer is refused, network errors read as no connection, a saved number naming Google (removed in DEV-1323) reads as none, and that a saved number survives a new client on the same defaults, as after a relaunch.

`MemberSignInWindowTests` (DEV-1323) cover the broker between the sign-in and its window: the window's answer reaches the sign-in once, a cancel or a failed window ends it with that failure, an answer before the wait is kept, and cancelling the sign-in is a cancel.
