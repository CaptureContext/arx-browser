# AgentToolsTests

Covers AgentToolsClient in temporary home folders with stand-in helpers, never the person's own `~/.local/bin` or agent configuration. `CommandLineToolTests` cover install, update from a different bundled helper and from an older setup link, uninstall, and refusing to replace or remove a file that isn't Arx's. They also cover a missing bundled helper, PATH detection however the folder is written, the profile line per shell, automated runs leaving the live clients inert, a live client read in a test failing loudly, and `RealHomeGuard` recognizing the real home folder (including through links) and refusing an uninstall, a credential-free `claude` run and a direct check there. The guard tests only use paths where a broken guard would still write nothing. `AgentAppsTests` cover adding Arx to Cursor, Claude Desktop and Codex files that already have other servers and settings, adding twice without duplicating, never replacing a file that isn't JSON, and creating a missing file. They also cover detection with the exact change shown, and Claude Code through a recorded `claude` command, including a failed command and a missing one. A real agent app picking Arx up is checked by hand.
