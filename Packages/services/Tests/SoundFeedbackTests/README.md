# SoundFeedbackTests

Covers SoundFeedbackClient's decisions (DEV-1256) through `deciding(isEnabled:isMicrophoneInUse:clock:player:)` with a recording player and a manual clock that moves at once (`TestClock` yields to every task on each advance, which took minutes on a busy Mac): every sound plays when nothing keeps it silent; the setting off, a tab playing sound, a tab in a call and the Mac's microphone in use each silence every sound; the same sound plays once in two seconds and again after; no sound starts before the one playing has finished; a silenced sound doesn't hold back the next one; a page report that arrives after a newer one is dropped; the test and preview clients are silent. It also checks that asking CoreAudio which processes use audio and whether any is recording returns without crashing (the result depends on the Mac), and that every sound's file is bundled, is as long as `SoundFeedback.length` says, and that the system accepts it as an interface sound, without playing anything.
