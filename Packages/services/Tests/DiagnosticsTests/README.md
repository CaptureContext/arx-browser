# DiagnosticsTests

Covers `DiagnosticsClient`'s readers and store (DEV-887) without the app: a macOS `.ips` report and a synthetic arm64 Crashpad minidump are reduced to `CrashReport`s that keep only the allowed fields (no URL from the stack, no path, no `asi`, termination reason or Mac identifier), helper reports count and other apps' don't, cut or foreign files never crash the readers, and a frame-pointer loop stops. `CrashReportStore` keeps each crash once, never moves the raw files, skips files past the retention, removes its own copies and problem report files only, and saves readable problem report files under unique names, keeping the newest 10. `GitHubIssue` prefills the issue form by field id with only the description, versions and file name, encodes reserved characters, cuts a long description to fit the address, and the form in `.github/ISSUE_TEMPLATE` keeps every field id the app fills.

The stall watchdog (DEV-1010) runs on a run-loop thread of the test's own: a 2 s block is logged once as it begins and once as it ends, with a symbolicated stack naming the blocking function and module UUIDs but no paths; short work is never a stall; strict mode logs the stall and ends the run with status 86; a stall that never ended reads as unended. MetricKit payloads are reduced to a hang diagnostic's duration and most-sampled stack, or the hang-time histogram, dropping exception text and other fields; Include diagnostics carries the last 7 days' stalls and reports, Remove deletes them, and problem reports saved before stalls still decode.

`CleanQuitLedger` (DEV-1018) is tested with its process checks, boot time and jetsam folders replaced: a clean quit records nothing, a run that never quit is recorded once with its counts, a marker whose process is still running is left alone and a second run never removes it, an unended stall, a crash report, a jetsam report and a later boot each name the exit, ended or earlier stalls do not, profiles keep separate markers named without their path, and Include diagnostics carries the ledger while Remove deletes it.
