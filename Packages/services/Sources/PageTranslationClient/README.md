# PageTranslationClient

Page translation on this Mac (DEV-904). `PageTranslationClient` (`pageTranslation`) detects a text's language with NaturalLanguage, asks the Translation framework's `LanguageAvailability` whether a pair is installed, translates batches with `TranslationSession(installedSource:target:)`, and names the person's first preferred language as the target. Nothing leaves the Mac; a language that isn't downloaded is reported, not fetched.

`PageTranslationScripts` are the scripts the app runs in the engine's developer world, which the page can't see: a language sample, the text nodes in and near view that aren't translated yet (code, inputs, editable text and `translate="no"` stay), putting translations in place with their surrounding spaces, and Show Original. `batches` keeps each script under the engine's source limit.

DEV-996 (behind `ARX_TRANSLATE`) adds `pairAvailability`, `translateSegments` and `targetLanguages`, which take `Options`: a `TranslationProvider` and Apple's `TranslationQuality`. `PageTranslationSegments.swift` holds the scripts that read a block, up to a line break, as a segment of runs (each text node a run, links and emphasis included; code and `translate="no"` kept; editable text, controls and hidden text left out) and put each run's translation back in its node. `arrange` turns a provider's answer, in the provider's order, into each run's text and, when the translation moved them, their order: the apply script then marks each inline piece's place with an empty comment and fills those places in the translation's order, and does the same inside a link or span that holds several runs (with words of no run that fall between them), so anything else in the block stays put; a run the translation split around another keeps its later words in a node of their own where they fall; words after kept code get a text node of their own, never read again; and `restore` puts each piece back at its own mark. Apple translates a segment as one `AttributedString` whose runs carry `arx-run:N` links, which the translation keeps on the words they became (`AppleTranslationRuns`); kept runs skip translation. Google (`GoogleTranslation`) gets each segment as HTML with `<a i=N>` and `<code i=N>` markers, POSTed to `translate.googleapis.com/translate_a/t` with `client=gtx` and `format=html`, the keyless endpoint Google's own page script uses, from an ephemeral session with no cookies. That isn't a documented API, and the page's text goes to Google.

Depends on BrowserCore and `_Dependencies`. AppFeature's `PageTranslationRouting` drives it; MainFeature's site menu reads a page's language with it.
