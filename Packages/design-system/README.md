# arx-design-system
Reusable native macOS presentation components and resources. Requires macOS 27 or later and Swift 6.4.
## Boundaries

May depend on core, dependencies, and extensions. Must not depend on services or features.
## Targets
- [AppUI](Sources/AppUI/README.md)
- [AppUITests](Tests/AppUITests/README.md)

New targets must have their own README and remain within the package role. Browser-owned code is new for Arx.
