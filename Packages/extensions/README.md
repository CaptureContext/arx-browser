# arx-extensions
Foundational Swift and Cocoa utilities exposed through two re-export targets. Requires macOS 27 or later and Swift 6.4.
## Boundaries

May depend on the selected utility packages and forks. Must not depend on core, services, UI components, or features.
## Targets
- [Files](Sources/Files/README.md): files and folders, copied from fxcodex.
- [LocalExtensions](Sources/LocalExtensions/README.md)
- [LocalUIExtensions](Sources/LocalUIExtensions/README.md)

Selected targets are wrappers only. See the project dependency selection record for fork and transitive-dependency policies.
