# _MCP

Exports the official Model Context Protocol Swift SDK, pinned to 0.12.1, and its logging API for the local stdio helper. Arx uses protocol 2025-11-25 with strict initialization and no sampling, elicitation, resources, tasks, or HTTP listener. Protocol types stay in services and helper containers; browser feature state uses BrowserCore values. Arx supplies bounded framing and a no-op protocol logger.

Sources: [SDK release](https://github.com/modelcontextprotocol/swift-sdk/releases/tag/0.12.1), [stdio transport](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports), [lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle).
