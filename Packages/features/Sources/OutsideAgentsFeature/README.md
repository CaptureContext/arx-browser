# OutsideAgentsFeature

The outside-agents component: the `arx` command, the MCP switch and the agent apps. Onboarding's "Work with outside agents" page and Settings' Local assistants sheet both show `OutsideAgentsView` over an `OutsideAgents` store.

- **Command-line tool:** `CommandLineToolClient` (AgentToolsClient). The component checks when it appears and again on `event(.applicationBecameActive)`. It offers Install when nothing is at `~/.local/bin/arx`, Update and Uninstall when the app's bundled helper differs from the installed copy, and Uninstall when they match. A file there that isn't Arx's is described and left alone. When `~/.local/bin` isn't on the login shell's PATH (or the PATH couldn't be read), it shows the line to add to the shell's profile with a Copy button. It never edits the profile.
- **MCP switch:** `State.mcp` comes from the parent, which owns the server; `ui(.setMCPEnabled)` only sends `delegate(.setMCPEnabled)`. Below it is a plain-language summary of DEV-659's standing permissions: a new agent sees nothing until it's granted access, reads of granted data don't ask, changes ask unless allowed for that agent, closing and deleting ask unless asking is turned off, and uploads always ask.
- **Agent apps:** `AgentAppsClient` lists Claude Code, Claude Desktop, Codex and Cursor, whether each was found and whether Arx is already added. Add… needs the command installed and MCP on (`addBlocker`). It only opens a review of the exact file and entry (or, for Claude Code, the `claude mcp add` command and the file it changes). Only Add in that review calls `agentApps.add`, so nothing is written without that click. A success sends `delegate(.connect(agent))`, and the parent issues the agent's credential. Copy Setup copies the snippet for setting it up by hand. It's the only option for an app with no supported way, such as Claude Code without its `claude` command.

The pasteboard belongs to the parent (`delegate(.copy)`). Strings are under `outsideAgents.*` in AppUI's catalog. Every control is a standard button or toggle with an accessibility label, and the review sheet has Cancel on Escape and Add on Return.
