# MigrationAssistantFeatureTests

Every suite that uses dependencies, a store or `@Shared` takes `@Suite(.dependencies)` (DEV-970). Without it, every test in the process shares one set of dependency test values, including swift-sharing's storage and `@Shared` references. A test then reads what another left behind, so it passes alone but fails on a repeat or next to another.

Reducer tests with injected `MigrationAssistantClient` closures: the live value's empty discovery, selection through preview, import and Done, cancellation that waits for the cancelled report, retry reusing the same plan ID, partial success with retryable categories, stale events from another plan, changed sources and unreadable data returning to selection, a missing destination, and an empty preview that can't start an import, and Safari's Full Disk Access (DEV-840): selecting it checks access, Review is refused while it's denied, Open System Settings goes through the client, coming back to Arx checks again and a granted answer is kept, and other sources never check.

`MigrationAssistantSnapshotTests` writes PNGs of the Customize view at the onboarding window's size, in light and dark, when `ARX_DESIGN_SNAPSHOTS` names a directory (DEV-791, DEV-842): choosing a source and the kinds of data with Passwords and sign-ins on, the review with the profile mapping and passwords straight from the browser, the same with a CSV per source profile, and the passwords step after the import (its intro, per-profile choices, and a report where one profile's write failed).

The profile mapping (DEV-842): a browser with profiles maps each to a new profile by default; a rename changes the plan without reading again; mapping onto an existing profile inspects again with `profileRoutes`; only offered profiles can be picked and a mapped profile's name can't be edited; mappings survive Back and a new profile gets the default, while another source starts over; files without profiles have no mapping; and Keep its spaces off maps every profile to the current one and reads the review again for that mapping.

`CredentialMigrationFeatureTests` covers Passwords and sign-ins as a kind of data (DEV-650, DEV-842) with every Keychain, presence and engine call replaced: loading picks the direct path or CSV (no writer, unknown browser, Safari's Passwords app) and reads nothing; after the import each source profile resolves to the Arx profile that got its tabs, the intro waits for Continue, presence comes before one Keychain read for every profile, choices are per profile, each writes into its own Arx profile, and undo takes back every batch, with a failed undo retrying only the batches still there; a profile without an Arx profile isn't read; denied, missing and unwritable keys lead to CSV; no presence check in the background, none after losing focus while authenticating, and no read without presence; closing before writing or a late read discards every profile's records, and an unselected profile is discarded rather than written; each CSV attaches to its source profile and imports into that profile's Arx profile right after the import, a bad file is reported for its profile and stays to retry or replace while the good one is done, CSV can be chosen over the Keychain and back, and Safari without a mapping takes one file for the whole source. In the assistant: the kind is offered only for browsers and is off until turned on; passwords alone can be reviewed and imported; a browser profile with only passwords joins the mapping while passwords are on; it learns the mapping on review, puts the mapped profiles in the plan so they're made, and starts after the import with the plan's destination; a cancelled import doesn't move passwords; CSV mode needs a file before Import; another source turns it off; dismissal or host removal discards records; and the assistant can't close while it writes. Clear Arx Data First is hidden on a fresh Arx and off by default; on, Review asks first (Back keeps everything), Remove and Continue hands the clear to the host, a cleared Arx is reviewed against its fresh destination with the mapping started over, a failed clear imports nothing, and with it off Review doesn't ask.
