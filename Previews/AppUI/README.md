# AppUI Preview

A standalone macOS app exercising AppUI's sidebar and command bar against deterministic BrowserCore fixtures. Uses TCA with structured actions and Pullback handlers. No network requests, engine, credentials, or persistence are required. The content pane is a fixture, not a web renderer.

Run `make preview`, or select AppUIPreview in the generated workspace. Cmd-L/Cmd-K opens the command bar; Cmd-T opens a new-tab search; Cmd-S toggles the sidebar; Cmd-Shift-N creates a folder; Cmd-Z undoes the last organization edit. Reset Preview restores the fixture from the Browser menu.

The URL bar, favorites, and workspace heading remain pinned while rows scroll beneath an adaptive material background. Click the workspace heading to collapse its saved tree; the selected saved tab and open tabs remain visible. Collapse state is independent for each space.

Rows select tabs or disclose folders. Folder icons animate their opening flap. Double-click a tab, or use Rename in any row’s context menu to edit; Return commits and Escape cancels. Dragging sidebar rows shows an insertion line without moving surrounding rows. Drop over the center of a folder to nest, or near its edges to insert between rows. At the bottom of an expanded folder, move the pointer horizontally to choose the indentation shown by the line. The space heading accepts saved-root drops. New Tab is an action button only. Favorites retain native grid reordering. Dropping between regular rows or into the blank area below them moves the tab into the regular section and removes its pin; this also works when that section is empty. Cycles and invalid ownership roll back through BrowserOrganization validation. Context-menu Move to provides alternatives to dragging. Trailing actions appear only on hover: selected or navigated pins reset, inactive pins at their saved destination are removed, and regular tabs close. Reset restores the saved URL and title and clears selection while retaining the pin. This engine-free preview has no renderer cache to clear; the reset action is the integration boundary for that behavior. These are in-memory prototype commands; production engine close cancellation, archive, and persistence are not implemented here.

Scroll horizontally over the sidebar to page between spaces, or use the bottom space buttons. Drop a tab onto a bottom space icon to move it, preserving its pinned or unpinned status. Drag-hover over an icon for half a second to page into that space before dropping elsewhere. The switcher and pager show spaces in the active profile. Vertical scrolling stays within each space. Switching spaces preserves a selected favorite when both spaces belong to the same profile. Saved and unpinned tab selections remain specific to their space. Sidebar visibility animates its width and the content pane; Reduce Motion disables these transitions. Drag the sidebar’s right edge to resize it, or double-click the edge to reset its width. Row selection uses the app’s highlight without the system blue focus ring.

When collapsed, hover at the left window edge to reveal the sidebar over the page. It stays visible while the pointer is inside and dismisses shortly after leaving. The page keeps its full width during this temporary reveal. The sidebar toggle or Cmd-S pins it open again; opening the command bar dismisses a temporary reveal.

The collapsed page has no sidebar button; use edge hover or Cmd-S to reopen it. The preview and Settings follow the system light or dark appearance through AppUI’s generated color resources. Interface strings use its generated localization resources. Appearance settings are available through the palette button at the bottom of the sidebar or Cmd-comma. Film grain can be disabled or adjusted using intensity and grain-size sliders, with a live sample and reset button. The static texture covers window chrome and the floating sidebar while leaving page content clear. These appearance preferences persist in the preview's own UserDefaults through Sharing; browser fixture data remains in memory.

Command-bar results include tabs, folders, spaces, commands, and new URL/search entries. Use arrow keys, Return, or a pointer. Escape or clicking outside dismisses. Searching or entering a URL creates preview metadata without loading a website. Icons are offline SF Symbol stand-ins for favicons.

Keyboard-focused rows use Return to rename and Space to select or disclose. Favorite tiles expose Rename and Move to Space in their context menu. `make test-preview` builds the app and runs the editing transaction tests in [Tests](Tests/README.md).

Validated organization edits are imported from SidebarFeature. The gallery remains engine-free and uses its own fixture reducer; production MainFeature owns actual browsing.

The fixed space switcher has an adaptive blurred upper edge when list content extends below the viewport. Renamed tabs retain their explicit names separately from page titles. Folder disclosure begins on the first click, and nested rows indent their whole highlight.
