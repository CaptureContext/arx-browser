# Glossary: Polish (pl)

Translators of Arx into Polish use these terms. A term here wins over any other choice.

## Language rules

- Address: informal second person singular ("ty"), as Apple's Polish macOS and its support pages do ("Jeśli nie masz pewności …", "nie przyznawaj dostępu …"). Never "Pan/Pani", never the plural "wy". Pronouns ("Ty", "Twój") are mostly dropped; when one is needed, Apple capitalizes it in running text ("próbowały Cię śledzić"). Verified: https://support.apple.com/pl-pl/149699 and https://support.apple.com/pl-pl/guide/safari/welcome/mac
- Capitalization: sentence case everywhere; only the first word and proper names take a capital ("Nowe okno prywatne", "Przenieś kartę do nowego okna").
- Verbs in buttons and menu items: imperative, second person singular ("Zamknij kartę", "Przypnij kartę", "Zachowaj"). Options that describe a lasting behaviour use the imperfective imperative ("Otwieraj strony w kartach", "Pytaj", "Zawsze pozwalaj").
- Save: Apple's Polish uses "Zachowaj" for saving files and documents; use it in menus and buttons ("Zachowaj obrazek jako…").
- Link: Apple's Polish says "łącze" (plural "łącza"), not "link".
- Tab and bookmark: a browser tab is "karta"; "zakładka" means a bookmark only. Never use "zakładka" for a tab.
- Punctuation and ellipsis: the single character "…" directly after the word, no space ("Drukuj…", "Ustawienia…").
- Quotation marks: „…” (low-high). Use them for UI names in running text.
- Plural categories: one, few, many, other (1 karta, 2–4 karty, 5 kart, 1,5 karty).
- Inflection: Polish nouns change form by case, so a term appears inflected in sentences ("w karcie", "do strefy"). The Translation column lists the base form first and common other forms after it.
- macOS Spaces: Apple calls them "przestrzenie" (singular "przestrzeń"), in Mission Control; each one shows a desktop, "biurko". Verified: https://support.apple.com/pl-pl/guide/mac-help/mh14112/mac
- Arx space: "strefa" (plural "strefy"), because "przestrzeń" belongs to macOS Spaces, "biurko" is the macOS desktop, "obszar" is a generic word for a screen area and "obszar roboczy" would mean a workspace; "strefa" is short, native and free.
- Length: Polish runs about 20 to 30 percent longer than English; prefer Apple's short forms in buttons.
