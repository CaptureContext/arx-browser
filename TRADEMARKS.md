# Name and icon

Arx's code is free software under the GNU General Public License, version 3 ([LICENSE](LICENSE)). The licence covers the code. It does not cover the name or the look that tell people a build comes from this project.

"Arx", the Arx app icon and the Arx wordmark are reserved by Maxim Krouk (CaptureContext).

## What you may do

- Build Arx from this repository and use it, unchanged or changed, for yourself.
- Say truthfully that your project is based on Arx or is a fork of Arx.
- Use the name to refer to Arx itself: in articles, reviews, comparisons and links.

## What needs a different name and icon

If you distribute a changed build to other people, give it its own name and its own icon, and don't present it as Arx or as endorsed by this project. That covers the app's name, bundle name, icon, wordmark, update feed and website.

[DEVELOPMENT.md](DEVELOPMENT.md) › Arx Dev describes the build settings that set them (`ARX_BUNDLE_ID`, `ARX_DISPLAY_NAME`, `ARX_APP_ICON` and the rest); `ArxEdition` in BrowserCore tells the app which build it is.

## Why

A browser handles passwords, payments and private pages. People who install something called Arx should be able to trust that it is the build this project signed and published.

## Questions

Open a discussion on the repository if you are unsure whether a use is fine.
